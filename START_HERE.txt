【使い方】
1. このフォルダをClaude Codeで開く
2. 下の線から下を全部コピーして、Claude Codeに貼り付ける
--------------------------------------------------
このフォルダのREADME.mdを読んで(README内の「案件一覧.dc.html」は design_prototype_dc.html のこと)、デザインを忠実に実装してください。

技術構成の指定:
- ホスティング: GitHub Pages(リポジトリ: fire-seisaku、静的サイト)
- データ: Firebase Firestore(案件・部品・検査・図面メタデータ)
- 写真: Firebase Storage(記録は写真のみ。動画は対応しない)
- Firebase設定は同梱の firebase-config.js を使う(接続済みの実プロジェクト)
- 写真はアップロード時にブラウザ側で長辺1600px・300KB程度に自動リサイズしてから保存
- FirestoreとStorageは現在テストモード。30日で失効するので、適切なセキュリティルールも書いて、設定手順を教えてください
- icons/ にアプリアイコン一式がある。favicon・apple-touch-icon・Webアプリマニフェストに設定し、スマホの「ホーム画面に追加」でアプリのように使えるようにする(PWA対応)

実装順(段階的に、各段階で動作確認できる形で):
1. 案件一覧+案件詳細(データ登録・進捗管理)
2. 写真アップロード+全端末同期
3. 工程ボード・部品資材・検査
4. 図面・仕様書ビューア
