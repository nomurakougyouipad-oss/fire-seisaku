## 概要（Overview）

消防車両（ポンプ自動車・水槽付ポンプ車・救助工作車・積載車など）の**製作工程を管理する業務アプリ**。製作現場の作業者が主な利用者で、PC とタブレット・スマートフォンの両方で使う。

製作工程は 7 段階：**設計 → 加工 → 艤装 → 塗装 → 電装 → 検査 → 納品**。

達成したいこと：
- 受注案件ごとの製作進捗・工程の把握
- 納期・スケジュール管理
- 部品・資材の発注・在庫管理
- 作業のチェック・検査記録
- 工程ごとの写真記録（現場スマホ撮影 → 全端末で共有）
- 原価・受注金額の可視化

## 画面一覧（Screens）

### 1. 案件一覧 / ダッシュボード（PC・メイン画面）— `01_pc_orders_table.png`
- **目的**：全製作案件を一覧し、進捗・原価・納期・状態を俯瞰。ここが起点。
- **レイアウト**：上部に赤グラデのナビバー（ブランド + メニュー）。本文は 26px パディングの縦フロー。見出し行の右に KPI 4 つ（進行中 / 今月納品 / 要注意 / 遅延）を大きな数字で右寄せ。ツールバー行（表示切替セグメント・検索・工程フィルタ・右端に「＋新規案件」）。その下にブループリント枠のデータテーブル。
- **テーブル列**：管理No（等幅・アクセント色） / 顧客・車両タイプ（2 行） / 現在の工程（工程タグ + ステップ番号 + 7 セグメントの工程ステッパー） / 進捗（% + バー） / 受注金額（右寄せ・アクセント色） / 材料原価（右寄せ） / 工数原価（右寄せ） / 納期（残日数、遅延は赤ベタ） / 担当 / 状態（順調=tag-neutral / 要注意=tag-outline / 遅延=accent-900 ベタ）。
- **進捗ラインの色分け**：順調=緑 `#4a9d6b` / 要注意=橙 `#e0912f` / 遅延=赤 `#a52a21`（凡例をツールバー下に表示）。工程ステッパーの完了・作業中セグメントもこの色を使う。

### 2. 工程ボード（PC・カンバン）— `02_pc_process_board.png`
- **目的**：7 工程を列にして案件カードがどの工程にあるかを俯瞰。別メニュー。
- **レイアウト**：7 列グリッド。各列ヘッダー = 工程番号 + 名称 + 件数、下にアクセント色の 2px 下線。列内に案件カード（管理No・遅延/要注意マーク・車両タイプ・顧客・工程ステッパー・納期・進捗%）。
- **挙動**：カードクリックで案件詳細（画面 3）へ遷移。ホバーで `--color-accent-100` に反転。本番はドラッグ&ドロップで工程移動できると理想。

### 3. 案件詳細（PC・工程別フォトログ）— `03_pc_case_detail.png`
- **目的**：1 案件を開き、工程ごとに写真を複数枚記録。
- **レイアウト**：ヘッダーに管理No・工程タグ・車両タイプ・顧客/シャシ/担当、右に全体進捗と納期。下に 7 工程を縦に並べ、各行は左 150px の工程ラベル（番号・名称・完了/作業中/未着手タグ・写真枚数）+ 右に写真サムネイル群（150×108px のブループリント枠）+「＋写真を追加」。
- **同期**：作業中工程（艤装）にはスマホ版と同一の写真枠 ID を使い「📱 スマホ撮影と同期」タグを表示（本番はクラウド同期）。

### 4. スマホ版 案件一覧 — `04_mobile_orders.png`（赤ヘッダー版 `06_mobile_orders_red.png`）
- **目的**：現場でのモバイル一覧。表を縦積みカードに変換。

### 5. スマホ版 案件詳細（工程写真 + メモ）— `05_mobile_detail.png`（赤ヘッダー版 `07_mobile_detail_red.png`）
- **目的**：1 工程ずつ表示し、各写真にメモを記入。
- **レイアウト**：ヘッダーに案件情報・全体進捗・「📐 図面・仕様書を開く」・工程タブ（横スクロール、完了✓/作業中/未着手）。選択工程の写真を大きく縦並び。各写真ブロック = 196px 画像枠（右下に ⤢ 拡大ボタン、左上に「n/総数」バッジ）+ 工程自動タグ + メモ入力欄。下に「＋写真を追加」（無制限に追加可）。下部アクションバー（編集・PDF出力・「次の工程へ進める →」）。

### 6. スマホ版 図面・仕様書 — `10_mobile_docs.png`
- **目的**：案件の図面・仕様書・書類を種別ごとに一覧、タップでプレビュー。画面 5 の「📐 図面・仕様書を開く」の遷移先。

## インタラクション & 挙動

- **ナビ遷移**：工程ボードのカード → 案件詳細。案件一覧の行 → 案件詳細（本番で実装）。スマホ詳細の「図面・仕様書を開く」→ 図面一覧。
- **写真**：スマホで撮影/ドロップ → 該当工程に添付。工程名は自動タグ付け。枚数無制限。拡大ビューアは横スワイプ + 矢印 + ドット。
- **写真同期**：同一案件・同一工程の写真は全端末で共有（クラウド同期。プロトタイプでは同一 ID で疑似再現）。
- **並べ替え**：スマホ一覧は納期順/進捗順のセグメント切替。
- **状態色**：進捗バー・工程ステッパー・状態タグは 順調=緑/要注意=橙/遅延=赤 で連動。
- **ホバー**：カンバンカードは `--color-accent-100` 反転。全インタラクティブ要素にホバー/プレス/`:focus-visible`（2px アクセント）を付与。
- **原価/金額**：受注金額・材料原価・工数原価は等幅・右寄せ・¥表記（`toLocaleString('ja-JP')`）。粗利（受注−材料−工数）列は将来追加候補。

## 状態管理（State）

- `lightbox: number | null` — 写真拡大ビューアの現在インデックス。
- `doc: number | null` — 図面プレビューの選択ファイル。
- `photos: Photo[]` — 工程の写真配列（追加で伸長）。
- 案件・部品・検査・図面データは API 取得に置き換え（プロトタイプはハードコード）。

## データモデル（想定）

- **Case（案件）**：id, customer, type(車両タイプ), chassis(シャシ), stageIndex(0-6), progress(%), due(納期), dueDays(残日数), staff, status(順調/要注意/遅延), orderAmount, materialCost, laborCost。
- **Stage（工程）**：7 固定（設計/加工/艤装/塗装/電装/検査/納品）、done/current/todo。
- **Photo**：id, stageTag, memo, 撮影日, 撮影者, 画像。工程に複数。
- **Part（部品・資材）**：kind(部品/資材), name, model, caseId, need, stock, supplier, price, eta, status(未発注/発注済/入荷待ち/入荷済)。
- **Inspection（検査）**：item, judge(合格/要調整/不合格/未判定), date, inspector, note。
- **Document（図面・書類）**：group(図面/仕様書/見積・書類), name, ext(PDF/DXF/XLSX), rev, size, date, file。

## デザイントークン（Industry デザインシステム）

ベースは **Industry**（ワイヤーフレーム調：明るい地に線画、角丸なし、ブループリント枠 + `+` 十字レジストレーションマーク）。本アプリはこれに**消防レッド**のアクセントを上書き。

**色（消防レッド ramp）**
- accent 基準 `#c8392e`、100=`#fdeeec` 200=`#fbd6d1` 300=`#f4b1a9` 400=`#ec8578` 500=`#dd5749` 600=`#c8392e` 700=`#a52a21` 800=`#7c1e18` 900=`#4d130f`
- 地 `#f2f2f3` / テキスト `#1d1f20`
- 状態色：順調 `#4a9d6b` / 要注意 `#e0912f` / 遅延 `#a52a21`
- **赤グラデ（採用・濃いめ）**：`linear-gradient(135deg, var(--accent-600), var(--accent-900))`。ヘッダー帯・プライマリボタン・現在工程タブに共通適用。ホバー=700→900、プレス=800→900。

**タイポグラフィ**：見出し = Barlow Condensed（`--font-heading`）、本文 = Barlow（`--font-body`）。等幅は ui-monospace 系（管理No・数値）。スライド最小 24px 等の制約は本アプリ対象外だが、モバイルのタップ領域は 44px 以上。

**枠**：カード・図・プライマリボタンは `.blueprint` + 四隅 `<i class="corner tl/tr/bl/br">`。角丸なし・ハーフライン枠・面塗りなし（プライマリボタンのみアクセント面塗り）。

**スペーシング/半径/影**：`--space-*`（density 0.85×）、`--radius-*`（4px）、`--shadow-sm/md/lg`。すべて `styles.css` の CSS 変数から取得（ハードコード禁止）。

**アイコン**：Lucide、stroke-width 1.5。

デザインシステム定義：`_ds/industry-…/styles.css`（トークンとコンポーネントクラスの唯一のソース）。
